# Avatar Call Companion

Necesito que hagas algo fantástico esta vez. Tienes que poder hacer una aplicación en donde permitas subir una foto como avatar y permitas que una inteligencia artificial responda, como una videollamada para llamar a ese avatar. Que puedas elegir la voz y que puedas elegir varias cosas, el carácter. Que sea básicamente una aplicación como Character AI, pero más personalizada para un solo avatar, que sea más interfaz tipo aplicación de llamadas de verdad, igual de WhatsApp o Instagram o algo así, que también puedas chatear con él y puedas hacer una llamada de voz, que las voces sean muy realistas, tipo las más realistas. Y no sé, algo así. Usa código "open source" en internet, GitHub y así para el modelo de IA, etcétera. ¿Sabes algo así? Está bien para animar el avatar, no quiero algo muy complicado. No, algo bastante bueno, no algo barato ni malo. Pero yo sé que hay modelos "open source" como el de Character AI, que puedes ponerlos tú. O puedes igual y todo reseñarlos, tipo que detecte la cara, tipo que con la cara anime las expresiones y así, y así, y asao. Y se mueva, que también si hay manos, te pueda mover las manos y el cuerpo, etcétera. Algo avanzado. Y así, detalles, un número bonito de la aplicación, algo que se pueda correr gratis, que no dependa de ninguna IA. Sí se puede. Intenta usar, no sé, importar un modelo ahí. Tal vez incluso usar, no sé, GPT-2 o esos que se pueden descargar rápido y así. O alternativas de IA o una IA, pero que no tenga ni API, que sea pública y que sea conocida y eso. Pues, no.
